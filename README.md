# 큼직 환율

안드로이드 브라우저에서 사용하는 큰 글씨 환율 계산기입니다. 별도 설치나 빌드, API 키 없이 GitHub Pages에서 작동합니다.

- 유로와 리라를 한국 원화로 환산
- 원 단위 반올림과 천 단위 쉼표
- `167000 → 16만 7천 원` 형태의 한글 단위 표시
- 소수점 입력은 두 자리까지 지원, 결과는 정수
- 직접 설정하는 간편 환율과 큰 다시 계산하기 버튼

## 자동 환율

사이트를 열 때와 페이지가 열려 있는 동안 한국시간 매일 00:00에 [Frankfurter](https://frankfurter.dev/) 공개 API의 최신 환율을 확인합니다. 페이지를 닫아 둔 경우에는 다음에 열 때 새로 확인합니다. 데이터 제공처가 자정에 새 시세를 발표하는 것은 아니며, 주말과 공휴일에는 이전 날짜의 자료가 표시될 수 있습니다. 하단의 **환율가격설정 정의** 버튼을 누르면 자료 기준일과 계산에 적용한 환율을 확인할 수 있습니다.

EUR 기준으로 받은 환율에서 원화 환율을 계산합니다. 환율을 직접 수정할 수도 있고, 다음 날 00:00에 다시 자동 환율을 적용합니다. 조회에 실패하면 이전에 성공적으로 받은 환율을 기기에 저장한 경우 그 환율을, 없으면 예시값을 표시합니다. 실제 환전 금액에는 은행·카드사 수수료와 매매기준율 차이가 반영될 수 있습니다.

## 환율 설정

자동 조회한 환율 또는 직접 입력한 환율을 올림해서 계산합니다. 100원 이상인 환율은 10원 단위, 100원 미만은 1원 단위로 올립니다. 아래 예시값은 조회에 실패한 경우에만 사용하며 현재 시세가 아닙니다.

- 유로: 1555.99 → 1560원
- 리라: 27.98 → 28원

수동 수정값은 페이지가 열린 동안 유지됩니다. 새로 열면 최신 환율을 다시 조회합니다. 금액 입력 아래의 **+1**, **+10**, **+100**, **+1,000** 버튼으로 금액을 더할 수 있습니다.

**다시 계산하기**는 금액·결과·금액 오류를 초기화하고 입력창에 포커스를 이동합니다. 선택 통화와 환율은 다음 계산을 위해 유지합니다.

## GitHub Pages에 올리기

1. GitHub에서 저장소를 만들거나 사용할 저장소를 엽니다.
2. 이 폴더의 `index.html`, `style.css`, `app.js`, `.nojekyll` 파일을 저장소 최상위에 올립니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. **main** 브랜치와 **/(root)** 폴더를 선택하고 저장합니다.
5. 배포가 끝나면 Pages 화면의 사이트 주소를 안드로이드 Chrome으로 엽니다. Chrome 메뉴의 홈 화면 추가 기능으로 바로가기를 만들 수 있습니다.

프로젝트 저장소의 하위 주소에서도 상대 경로로 작동합니다. 이 저장소의 Pages 주소는 `https://tns7gus-tech.github.io/easy_exchange_calc/`입니다.

## 로컬 실행

이 폴더에서 `python3 -m http.server 8080`을 실행한 후 http://localhost:8080 을 엽니다.

## 검증

`node test.cjs`로 반올림·한글 단위·입력값 검증을 실행할 수 있습니다.
